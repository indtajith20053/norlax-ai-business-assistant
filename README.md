# 🤖 Norlax AI Business Assistant

An AI-powered business assistant developed in Python to help customers explore business services, check prices, and calculate totals through function calling.

## 🚀 Features

- Product and service information
- Automated price calculations
- AI-powered customer interactions
- Function calling with an OpenAI-compatible API
- Error handling for unknown products and invalid quantities
- Sri Lankan Rupee (LKR) pricing

## 🛠️ Technologies

- Python
- Google Colab
- Groq API
- OpenAI Python SDK
- Large Language Models (LLMs)
- Tool Calling

## 💼 Business Use Case

Designed for Norlax AI Solutions to help customers learn about services such as website development, AI chatbots, business automation, and POS systems.

## 🧪 Testing

The assistant is tested with questions about service prices, quantity-based calculations, unavailable products, and unrelated questions.
